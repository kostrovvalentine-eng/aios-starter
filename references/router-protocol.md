# Router Protocol
*Last updated: 2026-08-04*

1. Follow the nearest `AGENTS.md`, then the root contract.
2. Identify the area and exact topic from the user's words.
3. Read the area router, then the selected content file.
4. Resolve project aliases through `projects/registry.json`.
5. Read `context/priorities.md` only when prioritization matters.
6. Read `connections.md` before using or describing current external state.
7. Use the documented live source when it conflicts with Markdown.

Never answer a routed question from memory merely because the topic looks familiar. If routing misses after a user correction, update the specific content file and the missing alias or route.
